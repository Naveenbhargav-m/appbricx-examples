# Templates

Starting points for your own Appbricx app. Each folder holds a complete
contract (`app.json`) you can apply as is, then change.

| Template | What it is |
|---|---|
| [Studio Bookings](../studio-bookings) | Class booking for a yoga and pilates studio. The app from the tutorial. |
| [Tablefor](./tablefor) | Restaurant reservations with a live kitchen board. |
| [Stride](./stride) | Fitness coaching: plans, workout logs and check-ins. |
| [Ledgerly](./ledgerly) | Personal finance: accounts, budgets, bills and insights. |
| [Kanbo](./kanbo) | Team project board with drag and drop. |
| [Atelier](./atelier) | Marketplace for handmade goods. |
| [Clinicly](./clinicly) | Clinic appointments with doctors, front desk and visit notes. |
| [Eventra](./eventra) | Event ticketing with QR passes and door check-in. |
| [Learnly](./learnly) | Online courses with lessons, quizzes and certificates. |
| [Relay](./relay) | Support desk with SLA timers and an email-to-ticket webhook. |
| [Nook](./nook) | Vacation rentals with availability, requests and reviews. |

Each folder also has a `template.json` (title, summary, screenshots, live
demo) that lists it in the template gallery at
[appbricx.com/templates](https://appbricx.com/templates).

To add a feature to an app you already have, see [blocks](../blocks),
[workflows](../workflows) and [components](../components), and
[the template format](../TEMPLATE_FORMAT.md).

See [Templates](https://appbricx.com/docs/templates) in the docs for how to
use them with your coding agent or the CLI.
